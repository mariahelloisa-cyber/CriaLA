# Assets de marca — SouCriaLA

Esta pasta é o local esperado para os arquivos oficiais da logo. Assim que
adicionados, `src/components/navigation/brand.tsx` passa a exibi-los
automaticamente (com fallback para o placeholder atual caso o arquivo não
seja encontrado) — nenhuma alteração de código é necessária.

Arquivos esperados:

- `soucriala-logo.svg` (ou `.png`) — logo completa, usada na Sidebar expandida
  e no painel de branding da tela de login.
- `soucriala-mark.svg` (ou `.png`) — versão reduzida/símbolo, usada na Sidebar
  recolhida (collapsed) e no favicon.

Formatos preferidos: SVG (nítido em qualquer tamanho). PNG com fundo
transparente também é suportado.

Até que os arquivos oficiais sejam adicionados aqui, a interface exibe um
placeholder neutro nas cores da marca (pink #EB1F7E) — não é a logo oficial.
